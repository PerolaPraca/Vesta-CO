# VESTA.CO — Vercel

Projeto estático pronto para publicação no Vercel.

## Arquivos
- `index.html` — página principal, incluindo a verificação do Google Search Console.
- `sitemap.xml` — sitemap do site.
- `robots.txt` — permite rastreamento e aponta para o sitemap.
- `vercel.json` — configurações simples de segurança/URLs.

## Search Console
Após o deploy, envie no Google Search Console:
`https://vesta-co.vercel.app/sitemap.xml`

## Vercel
Framework: Other
Build Command: vazio
Output Directory: `.`
